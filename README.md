# Networking Lab

Laboratorio práctico complementario del libro **NETWORKING - Fundamentos, Arquitecturas y Despliegue Práctico**. 15 laboratorios para aprender redes y seguridad desde cero, construyendo una infraestructura completa paso a paso.

**Sitio del laboratorio:** https://asideloko.github.io/Networking-Lab/
**Libro complementario:** https://leanpub.com/networking-fundamentos-implementacion

Cada laboratorio está vinculado directamente con el tema correspondiente del libro, pensado para llevar la teoría a la terminal con ejercicios ejecutables. Los ejercicios están diseñados principalmente para entornos Linux y Windows, complementándose con Cisco en escenarios que requieren configuraciones específicas.

## Cómo usar este repositorio

La forma más simple es entrar directamente al sitio publicado:

**https://asideloko.github.io/Networking-Lab/**

No necesitas instalar nada para seguir los laboratorios: el sitio ya está listo para consultarse desde el navegador.

## Contribuir o correr el sitio localmente

Si quieres modificar el contenido o correr el sitio en tu propia máquina:

1. Clona el repositorio:
   ```
   git clone https://github.com/asideloko/Networking-Lab.git
   ```
2. Instala MkDocs y el tema Material:
   ```
   pip install mkdocs mkdocs-material
   ```
3. Sirve el sitio localmente:
   ```
   mkdocs serve
   ```
4. Abre tu navegador en `http://127.0.0.1:8000`.
